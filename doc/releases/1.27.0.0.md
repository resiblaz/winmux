# 天枢 · Dubhe 1.27.0.0 (+ 天枢 Mobile v0.1.0)

This milestone release introduces the new **天枢 · Dubhe** brand and Big Dipper constellation icon across Windows, Android, and Web, a redesigned three-level workspace sidebar with a serene dark palette, a built-in encrypted Remote Bridge with Cloudflare Quick Tunnel support, and the first companion Android app (**天枢 Mobile v0.1.0**) for monitoring terminals, approving AI agent actions, and uploading images or files directly from your phone.

## Features

### Desktop Workspace Sidebar & Chrome
- **Three-level workspace tree**: Organizes workspaces, terminal surfaces, and split panes with live agent badges (Claude, Codex, AGY), activity dots, listening port pills, Git branch display, and drag-and-drop reordering.
- **Linear-inspired serene dark palette**: Replaces high-contrast solid selection blocks and heavy gray dividers with a cohesive deep graphite theme (`#111318`), opaque hairline borders (`#22262F`), soft translucent selection highlights, segmented status filters (`All`, `Alerts`, `Active`), a right-aligned vector pushpin badge, and a bottom remote-status strip.
- **Built-in Remote Control flyout**: Start/stop the bundled standalone `winmux-bridge.exe` sidecar directly from the sidebar, scan a QR code or copy a `winmux://pair?...` link, refresh QR codes on demand, install Claude/Codex approval hooks in one click, manage paired devices with instant revocation, and toggle a Cloudflare Quick Tunnel with remembered auto-start.
- **Quick workspace actions**: Added right-click **Open Directory** and **Copy Path** actions in the workspace context menu.

### Remote Bridge & Web Console
- **Standalone zero-dependency `winmux-bridge.exe`**: Bundled via Node.js SEA with code cache for fast startup and zero Node.js runtime requirement on user machines.
- **End-to-end TLS & security hardening**: Automatically generates a local self-signed ECDSA certificate with SHA-256 fingerprint pinning, enforces Bearer token authentication on all mobile APIs and WebSockets, restricts `/api/local/*` and `/api/hooks/*` to true loopback requests (blocking reverse-proxy header spoofing), rate-limits pairing attempts, and disconnects revoked devices immediately.
- **Built-in Web PWA console**: Lightweight browser interface with delegated event handling, search, terminal streaming, and interactive decision/question approvals.
- **Phone-to-PC image & file upload**: Authenticated `POST /api/files/upload` endpoint (up to 25 MB, sanitized filenames, stored under `%LOCALAPPDATA%\Winmux\remote-bridge\uploads\YYYY-MM-DD\`) so agents like Claude Code and Codex can directly inspect screenshots and files sent from mobile.

### Winmux Mobile v0.1.0 (Android)
- **QR code instant pairing & seamless Wi-Fi / 5G switching**: Scans desktop QR codes, races LAN and remote endpoints in parallel (Happy Eyeballs), auto-syncs updated Cloudflare tunnel URLs while on Wi-Fi, and reconnects automatically on foreground resume, screen unlock, network switch, or stale socket detection.
- **Real-time ANSI terminal & ergonomic mobile controls**: WebSocket delta streaming, off-main-thread ANSI color parsing, sibling pane switcher, system back-gesture navigation, fixed one-row quick keys (`↑`, `↓`, `⏎`, `Tab`, `Esc`) with FIFO key queue and haptic feedback, expandable D-pad and long-press protected `Ctrl+C`, quick prompt snippets, and one-tap image/file attachment upload.
- **Agent approvals, usage & model control**: Push notifications and risk-graded approval cards for Claude/Codex hooks, interactive question cards, usage tracking, live `/model` switching, split-pane actions, and device management.

## Performance & Fixes

- **Desktop**: Eliminated per-refresh COM allocations in `WorkspaceSidebar` via POD row diffing and throttled updates; replaced dependent width animations with GPU-composited transforms; added zero-process `.git/HEAD` fast path; memoized process-tree port scanning; reused shared WinHTTP sessions and persistent multi-request Named Pipe IPC with reused `OVERLAPPED` events.
- **Remote Bridge**: Reused persistent Named Pipe connections, added adaptive idle polling and append-only terminal delta streaming, fixed WebSocket fragmentation and tunnel start/stop races, and hardened multi-line Codex TOML hook backup/restore.
- **Android**: Fixed edge-to-edge status/navigation bar insets on `TerminalScreen` and nested `Scaffold` layouts, eliminated WebSocket reconnect races and 401 retry loops, and raised remote tunnel probe timeout to 8 seconds with per-endpoint error diagnostics.

## Download and run

### Windows (Desktop)
Download `winmux_1.27.0.0_windows_x64.zip`, extract the entire archive, and run `winmux.exe` inside `winmux-1.27.0.0`. Keep the DLLs, resources, `bridge/`, `settings/`, and `.portable` marker together.

Use `wmx.exe` for console output and workspace CLI commands. Requires Windows 10 build 19041 or later (including Windows 11) on Intel/AMD x64.

### Android (Companion App — v0.1.0)
Download `winmux_mobile_v0.1.0_android.apk` and install it on Android 8.0 (API 26) or newer. Open Winmux on your PC, click the Remote Control button in the sidebar, and scan the QR code to pair.

To use remote terminal reading and input from mobile, enable `experimental.workspaceAutomation.allowContentRead` and `experimental.workspaceAutomation.allowInput` in your Winmux `settings.json`. For 5G / outside-home access, install `cloudflared` (`winget install Cloudflare.cloudflared`) and toggle Quick Tunnel inside the desktop Remote Control flyout.

## Upgrade

Close Winmux normally so its session state is saved. Back up your existing `settings` directory, extract `winmux_1.27.0.0_windows_x64.zip` into a separate directory, and copy your saved `settings` directory into `winmux-1.27.0.0` before launching.

Because portable installations isolate their single-instance mutex by executable path, `winmux-1.27.0.0` can be tested side-by-side with an older portable folder (ensure only one instance runs the Remote Bridge on port `47710` at a time).

If you previously installed a debug-signed pre-release Android APK, uninstall it once before installing the release-signed `winmux_mobile_v0.1.0_android.apk`.

## Known issues

- Working-directory restoration requires the shell prompt to report its directory through OSC 7 or OSC 9;9. Without directory reporting, restoration falls back to the terminal's startup directory.
- Restoring a layout starts new shell processes. Running commands and process memory are not resumed.
- Cloudflare Quick Tunnel URLs are ephemeral per tunnel restart; connecting once on home Wi-Fi automatically syncs the latest URL to Winmux Mobile, or you can re-scan the refreshed QR code.
- Narrator, High Contrast, and mixed-DPI behavior still require validation on the target Windows configuration.
