# Winmux 1.26.3.0

This update adds notification badges to individual terminal tabs and expands Vim navigation, search, and copying on Intel/AMD Windows x64.

## Features

- Each terminal tab shows a bell badge with its own unread notification count. Hover over the badge to see the latest unread notification, so you can identify which terminal finished a task or needs attention even when another terminal is selected.
- Vim Normal and Visual modes now support `gg` and `G` for the beginning and end of output, including scrollback. `10gg` or `10G` jumps to logical line 10; `0`, `^`, and `$` jump within a logical line, keeping soft-wrapped rows together.
- Prefix Vim motions with a number, such as `5j`, `3w`, or `2$`. In Normal mode, use `yy`, `5yy`, or `y5y` to copy one or more logical lines without moving the browsing position.
- Use `/` to search from the browsing character, then `n` or `N` to repeat the confirmed search forward or backward. Searches support numeric prefixes, wrap around the buffer, and extend Visual selections when confirmed. Escape or the search box's close button cancels without changing the browsing position or selection.

## Fixes

- Reading a notification clears only the matching terminal and pane's reminder. Other unread notifications stay visible; marking notifications as read, clearing history, closing terminals, and evicting old history also update the tab badges.
- Vim search input stays inside the search box instead of reaching the shell. Typing a query previews matches without moving the browsing cursor, and an empty confirmed query reuses the last confirmed search text.
- Held digits and prefix keys do not repeatedly append counts or complete commands. Unsupported commands and leaving navigation reset pending counts and operators.

## Download and run

Download winmux_1.26.3.0_windows_x64.zip, extract the entire archive, and run winmux.exe inside winmux-1.26.3.0. Keep the DLLs, resources, settings directory, and .portable marker together.

Use wmx.exe for console output and workspace CLI commands. This release supports Windows 10 build 19041 or later, including Windows 11, on Intel/AMD x64.

## Upgrade

Close Winmux normally so its session state is saved. Back up the existing settings directory, extract this release into a separate directory, then copy your saved settings directory into winmux-1.26.3.0 before starting it.

Existing shell, font, Vim navigation, and shortcut preferences are preserved. Vim navigation must be enabled for the active profile; `Alt+V` enters Normal mode with the default binding. Terminal tab badges use the existing notification system and need no new setting.

## Known issues and scope

- Working-directory restoration requires the shell prompt to report its directory through OSC 7 or OSC 9;9. Without directory reporting, restoration falls back to the terminal's startup directory.
- Restoring a layout starts new shell processes. Running commands and process memory are not resumed. Notification history and Vim navigation state are not persisted across restarts.
- Narrator, High Contrast, and mixed-DPI behavior still require validation on the target Windows configuration.
