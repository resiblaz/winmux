# Winmux 1.26.2.0

This update adds Vim paragraph navigation, improves Visual selection, and makes numeric workspace and terminal switching faster on Intel/AMD Windows x64.

## Features

- In Vim Normal and Visual modes, use `{` and `}` to jump to the previous or next paragraph boundary. Both motions support held-key repetition and stop at the available text bounds.
- With up to nine workspaces, `Ctrl+1` through `Ctrl+9` now switch immediately when the digit is pressed. With up to nine terminals in the current workspace, `Alt+1` through `Alt+9` do the same. You can keep the modifier held while switching between single-digit destinations.
- With ten or more destinations, numeric navigation continues to accept workspace or terminal numbers from 1 through 99 and switches when the modifier is released. The threshold is evaluated independently for workspaces and terminals in the current workspace.

## Fixes

- Vim Visual selection now includes both endpoint characters for character, word, and paragraph motions. Copying a selection includes its final period or wide character; pressing `v` then `y` copies the browsing character itself.
- Copying or cancelling Visual selection preserves the active browsing character. Numeric shortcuts continue to respect custom bindings and explicit unbindings, consume key releases, and suppress held-key repetition.

## Download and run

Download winmux_1.26.2.0_windows_x64.zip, extract the entire archive, and run winmux.exe inside winmux-1.26.2.0. Keep the DLLs, resources, settings directory, and .portable marker together.

Use wmx.exe for console output and workspace CLI commands. This release supports Windows 10 build 19041 or later, including Windows 11, on Intel/AMD x64.

## Upgrade

Close Winmux normally so its session state is saved. Back up the existing settings directory, extract this release into a separate directory, then copy your saved settings directory into winmux-1.26.2.0 before starting it.

Existing shell, font, Vim navigation, and shortcut preferences are preserved. Vim navigation must be enabled for the active profile; `Alt+V` enters Normal mode with the default binding.

## Known issues and scope

- Working-directory restoration requires the shell prompt to report its directory through OSC 7 or OSC 9;9. Without directory reporting, restoration falls back to the terminal's startup directory.
- Restoring a layout starts new shell processes. Running commands and process memory are not resumed.
- Narrator, High Contrast, and mixed-DPI behavior still require validation on the target Windows configuration.
