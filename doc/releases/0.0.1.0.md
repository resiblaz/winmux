# Winmux 0.0.1.0

The baseline Winmux portable release for Intel/AMD Windows x64.

## Features

- Workspace sidebar for organizing projects, terminal tabs, and split panes.
- Workspace layout restoration, including active tabs and working directories.
- Vim navigation and text selection with Alt+V.
- Coding-agent notifications and local history.
- Workspace snapshots and automation through the wmx workspace CLI.

## Download and run

Download winmux_0.0.1.0_windows_x64.zip, extract the entire archive, and run winmux.exe inside winmux-0.0.1.0. Keep the DLLs, resources, settings directory, and .portable marker together.

Use wmx.exe for console output and workspace CLI commands. The target is Windows 10 build 19041 or later, including Windows 11, on Intel/AMD x64.

## Existing portable installations

Close Winmux normally so its session state is saved. Back up the existing settings directory before upgrading. Extract the new release into a separate directory, then copy your saved settings directory into the new winmux-0.0.1.0 directory before starting it.

## Scope

This release distributes the portable x64 ZIP. Registered-package settings use a separate settings store.
