# 项目、任务双视图与 Agent 管理交互参考

导航范围已按用户追加要求修正：正式应用保留原 Workspace 侧边栏，项目管理仅在
Task 面板内。这里的全局项目侧栏是早期参考，不再作为正式布局依据。

本目录记录 2026-09-07 用户确认的交互草案。打开 [index.html](index.html) 即可试用，
无需构建 Windows Terminal，也不需要 Runtime、网络服务或第三方脚本。

界面使用演示数据，刷新页面恢复初始状态。默认展示保留的任务列表和完整详情，
可以切换看板、打开侧栏 Agent 管理，以及从新建任务返回管理页面。

正式约束以[详细设计](../../specs/drafts/workspace-projects/README.md)和已有
Task/Agent 架构为准；本文件不能作为生产执行状态机或数据库实现直接移植。

## 可以评审的内容

- 项目切换、当前/全部项目、搜索与筛选、列表/看板切换。
- 完整任务详情、目标与验收、执行记录、补充要求和生命周期操作入口。
- 看板起拖、落点、执行/停止反馈、验收和退回修改。
- 全局 Agent 管理、模型/指令编辑、预览、复制、归档/恢复和项目默认设置。
- 从任务草稿进入 Agent 管理并返回后保留输入。

## 演示简化与正式实现的区别

| 演示内容 | 正式实现要求 |
| --- | --- |
| 计时器模拟启动和交付 | 真实 Run 投影及显式交付命令；不得按计时器或退出码判断产品进度 |
| 内存数组、姓名查找和即时更新 | 稳定 ID、版本/CAS、Runtime 单写、receipt、冲突和结果未知处理 |
| 保存公共 Agent 后下次模拟启动读取当前配置 | 已固定 Task/Run 不追随公共配置更新，必须显式更新 Task 上下文 |
| 归档后演示要求重新选择执行者 | 已固定配置的真实 Task 仍可继续与重试；归档限制新选择 |
| 表单阻止重名 Agent | 真实 Agent 允许同名，用 ID/版本消歧 |
| 验收复选框本地更新 | 有版本校验的持久命令，确认完成具有原子性 |
| 清理只改显示标记、删除可用内存撤销 | 原 Runtime Worktree 交付、生命周期恢复、不可伪撤销的删除和最小 tombstone |
| 任务结果放入演示“结论” | 原生保留 Task 与 Summary/History 记录隔离 |
| 窄网页把看板分行 | 原生采用可读列宽与横向导航，保持状态顺序和键盘路径 |

原型是本仓库交互设计的自有参考，没有复制 Multica 源码或 UI 资产，也未嵌入
Codex 可视化运行时。新增原生组件按详细设计拆分，不沿用这个演示单文件的结构。
