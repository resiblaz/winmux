# Winmux 1.26.0.0

The first Winmux GitHub release for Intel/AMD Windows x64. The `v1.26.0.0` tag continues the inherited upstream `v1.25.*` tag history.

## Features

- Workspace sidebar for organizing projects, terminal tabs, and split panes.
- Independent workspace and terminal navigation through 99: hold Ctrl to select a workspace, or Alt to select a terminal within the current workspace, type its number, then release to confirm.
- Workspace layout restoration, including active tabs and working directories.
- Vim navigation and text selection with Alt+V.
- Coding-agent notifications and local Codex history.
- Workspace snapshots and automation through the wmx workspace CLI.

## Download and run

Download winmux_1.26.0.0_windows_x64.zip, extract the entire archive, and run winmux.exe inside winmux-1.26.0.0. Keep the DLLs, resources, settings directory, and .portable marker together.

Use wmx.exe for console output and workspace CLI commands. The target is Windows 10 build 19041 or later, including Windows 11, on Intel/AMD x64.

## Existing portable installations

Close Winmux normally so its session state is saved. Back up the existing settings directory before upgrading. Extract the new release into a separate directory, then copy your saved settings directory into the new winmux-1.26.0.0 directory before starting it.

## Scope

This release distributes the portable x64 ZIP. Registered-package settings use a separate settings store. Layout restoration starts new shells; running services and commands need to be restarted.
