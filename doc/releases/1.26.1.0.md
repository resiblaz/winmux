# Winmux 1.26.1.0

This update improves the default font and shell selection for portable installations on Intel/AMD Windows x64.

## Features

- Fresh portable settings use JetBrainsMono Nerd Font Mono at size 14 for all profiles. Install that font for the intended appearance; Consolas is used as a fallback when it is unavailable.

## Fixes

- Portable settings without an explicit default profile now select an installed PowerShell 7 profile on the machine running Winmux, falling back to Windows PowerShell 5.1 when PowerShell 7 is unavailable.
- Default initialization preserves an explicitly selected shell, custom Command Prompt profile names, and existing font preferences.

## Download and run

Download winmux_1.26.1.0_windows_x64.zip, extract the entire archive, and run winmux.exe inside winmux-1.26.1.0. Keep the DLLs, resources, settings directory, and .portable marker together.

Use wmx.exe for console output and workspace CLI commands. This release supports Windows 10 build 19041 or later, including Windows 11, on Intel/AMD x64.

## Upgrade

Close Winmux normally so its session state is saved. Back up the existing settings directory, extract this release into a separate directory, then copy your saved settings directory into winmux-1.26.1.0 before starting it.

Existing settings retain their chosen shell and font. The new font default applies to fresh settings; an existing installation can select JetBrainsMono Nerd Font Mono at size 14 in Settings. Automatic shell selection applies when defaultProfile is absent.

## Known issues and scope

- Working-directory restoration requires the shell prompt to report its directory through OSC 7 or OSC 9;9. Without directory reporting, restoration falls back to the terminal's startup directory.
- Restoring a layout starts new shell processes. Running commands and process memory are not resumed.
- Narrator, High Contrast, and mixed-DPI behavior still require validation on the target Windows configuration.
